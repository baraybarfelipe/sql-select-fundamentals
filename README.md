# sql-select-fundamentals
1)¿Por qué es mala práctica usar SELECT * en producción?:
Es mala práctica usar select * en producción ya que no define ningún análisis concreto, brinda información innecesaria y quizás excesiva para quien se le otorga, en un gran volumen de datos es mejor seleccionar unicamente los datos fundamentales para optimizar el rendimiento.
2)¿Por qué son importantes los alias para un stakeholder no técnico?
 Importa ya que para alguien que no está familiarizado en produndidad con la base de datos, Total_amount puede generar confusiones pero total_de_venta, por ejemplo, es más visual e intuitivo.
